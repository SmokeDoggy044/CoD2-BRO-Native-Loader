# Controller button prompts

PNG button glyphs from Kenney's **Input Prompts** (version 1.5A, www.kenney.nl/assets/input-prompts), 128 px
("Double") versions, unchanged except their file names: each set's folder names its files after the pad tokens of
`src/input/bindings.h` (`a.png` = the bottom face button, `lb.png`, `dpad_left.png`, ...). `src/text/key_prompts.cpp`
draws them over the game's button icons while a gamepad is in use.

| Folder | Kenney set |
|---|---|
| `xbox/` | Xbox Series (coloured A B X Y, View / Menu / Share) |
| `playstation/` | PlayStation Series: PS5 (Create / Options, touchpad) |
| `playstation4/` | PlayStation Series: PS4's Share / Options and touchpad (the rest from `playstation/`) |
| `nintendo/` | Nintendo Switch (by position: the bottom button is B) |
| `steam/` | Steam Deck (also the Steam Controller) |
| `paddles/` | Steam Deck's L4 / R4 / L5 / R5: the back buttons of any pad |
